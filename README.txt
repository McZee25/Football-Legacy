FOOTBALL LEGACY v1.5 - WEBSITE

Folder ini siap dipublikasikan sebagai website statis menggunakan GitHub Pages.

CARA PUBLISH DARI HP ATAU PC:
1. Buat repository baru di https://github.com/new
2. Beri nama: football-legacy
3. Pilih Public, lalu buat repository.
4. Upload file index.html dari folder ini ke repository (Add file > Upload files).
5. Buka Settings > Pages.
6. Pada Build and deployment, pilih Deploy from a branch.
7. Pilih branch main dan folder /(root), lalu Save.
8. Tunggu beberapa menit. Link website biasanya berbentuk:
   https://USERNAME.github.io/football-legacy/

Catatan: GitHub Pages memerlukan akun GitHub. Game ini merupakan website statis dan tidak memerlukan server backend untuk berjalan.
